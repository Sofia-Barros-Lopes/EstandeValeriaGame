# 🌾 Estande Valéria

Bem-vindo ao repositório oficial do **Estande Valéria**, um jogo aconchegante inspirado no clássico estilo de farming RPG de *Stardew Valley*! 

Este projeto foi desenvolvido como parte do curso **Pronatec - Negócios Inovadores com IA** no IFSP (Instituto Federal de São Paulo) - Campus São João da Boa Vista, explorando o uso de Inteligências Artificiais como ferramentas de apoio no desenvolvimento de software e design criativo.

---

## 🎮 Sobre o Jogo

O **Estande Valéria** simula a rotina de gerenciamento de uma fazenda charmosa e acolhedora. O jogador pode interagir com o ambiente, cuidar de animais, explorar o mundo ao redor e vivenciar uma experiência leve e relaxante inspirada em grandes clássicos do gênero.

---

## 🤖 O Papel das IAs no Projeto

O desenvolvimento deste jogo contou com a colaboração de diferentes inteligências artificiais para otimizar o fluxo de criação:

*   **Claude:** Auxílios na estruturação lógica, resolução de problemas de código e refinamento de scripts.
*   **Antigravity:** Apoio no desenvolvimento e estruturação geral do projeto.
*   **Gemini:** Criação de assets visuais, avatares de personagens e elementos gráficos do mundo.
